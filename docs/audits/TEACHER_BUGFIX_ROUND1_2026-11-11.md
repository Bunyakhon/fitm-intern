Response Array เดิมหรือ metadata `{rows,total,years,offset,limit}` ตาม opt-in. เพิ่ม GET `/api/teachers/project-advisor-requests/:id` คืน DTO เดียวกับ List พร้อม superseded_at. Controller/Teacher guards เดิม, Hydrate กรอง requested_advisor_teacher_id; ไม่พบคืน404. Accept/Reject Business Logic ไม่เปลี่ยน.
3. Supervision Student List: GET เดิม `/api/supervision/teacher/students`, limit default10/allowlist10,25,50. Callersปัจจุบันทั้ง Dashboard/Teacher Supervision ปรับแล้ว. Response `{students,total,years,offset,limit}`/Academic Projectionเดิม. ไม่มี Models/Schema Changes และไม่มี N+1 Detail เพื่อเติม List.
4. Documents: `year=unknown` รองรับเฉพาะ Reader kinddocuments; ค่าอื่นตามเดิม. ไม่ส่ง year/semester รวมUnknown. ระบุปีหรือภาคใช้ Structured Period จริง; Unknownอยู่ท้ายทั้งasc/desc. ไม่มีDate-derivedYear/StudentCode-derivedYear.

6. เพิ่ม GET `/api/teachers/project-documents/viewer-assets/pdf.mjs`, `pdf.worker.mjs`, `cmaps/:asset`, `standard_fonts/:asset` สำหรับ **Library Assets เท่านั้น** โดย FixedFile/Group/Basename/Extension Allowlist ใต้ Installed pdfjs-dist; ไม่มี Student ID/Storage Root/Upload Filename ในการ resolve. ส่วนนี้ไม่มีJWTเพราะเป็นโค้ดLibraryที่Browserต้องimport, ไม่ใช่สิทธิ์อ่านเอกสาร. ไม่เปิด Static Directory Listing/Private Storage.
