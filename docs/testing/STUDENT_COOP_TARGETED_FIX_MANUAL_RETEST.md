# Student Coop — Manual Retest เฉพาะ 9 Findings

วันที่: 9 พฤศจิกายน 2026 (Asia/Bangkok). ทุกกรณีเริ่มต้น **NOT TESTED — PENDING USER RESULTS**. เอกสารนี้เป็นขั้นตอนสำหรับผู้ใช้ ไม่ใช่ผลทดสอบหรือ Runtime Acceptance.

## การเตรียม

- ใช้ Chrome เปิด Student → โครงการสหกิจศึกษา; เปิด DevTools → Network (Fetch/XHR, Preserve log, Disable cache) และ Console. ไม่คัดลอก Authorization headers, JWT, Cookies หรือข้อมูลส่วนตัวลงรายงาน/ภาพ/ไฟล์ HAR.
- ใช้บัญชีทดสอบ Student A/B และ Teacher ที่ได้รับอนุญาตอยู่แล้ว. กรณี Teacher Accept/Reject ใช้ Chrome profile แยกเพื่อรักษา Student session. ไม่ใช้บัญชีจริงที่มีงานสำคัญสำหรับ mutation/fault scenarios.
- HTTP faults, unknown response, delayed response และ COMMIT acknowledgement loss ต้องใช้สภาพแวดล้อมแยก/เครื่องมือจำลอง fault ที่ผู้ใช้ควบคุม. Codex ไม่ได้สร้างบัญชี เปิดสิทธิ์ เปลี่ยนข้อมูล ตั้ง fault หรือรันเครื่องมือใดในรอบนี้.
- Topic Draft อยู่เฉพาะหน้าเดิม ไม่มี server draft/local persistence ใหม่. บันทึกข้อความร่างที่ต้องการเก็บก่อนยืนยันแทนร่าง/reload/logout.

- บันทึก Case ID, browser/environment, ขั้นตอนจริง, HTTP status/code และสิ่งที่เห็น โดยไม่แนบ credentials/token/ข้อมูลส่วนตัว. ผลยัง PENDING จนผู้ใช้รายงาน.
